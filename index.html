  • Voice Pipeline: End-to-end voicebot for inbound and outbound calling — Twilio Media Streams (G.711 µ-law, 8 kHz) → WebSocket → VAD → streaming STT → LangGraph agent → streaming LLM → streaming TTS, with barge-in detection and echo guard for natural interruption handling.
  • Agentic Workflows: Multi-step reasoning in LangGraph using typed state, conditional edges and checkpointing, with interrupt-based human-in-the-loop approval gating for high-risk actions such as refunds.
  • RAG Pipeline: Structure-aware chunking with metadata, hybrid BM25 + vector retrieval and cosine-similarity search; reranking disabled on the voice path after measuring a ~150 ms latency penalty.
  • Context & Memory: Three-tier state system (context window, conversation memory, persistent facts) with token budgeting and rolling summarisation to prevent context saturation and control cost.
  • APIs & Tool Calling: REST, WebSocket and SSE streaming endpoints via FastAPI with correlation IDs, plus an MCP server and tool registry with timeout and retry handling.
  • Prompt & Cost Optimisation: Two-tier routing (regex/intent classifier → fast model → main model) with per-turn latency budgeting across endpointing, STT, agent reasoning and TTS.
  • Deployment & Scale: Multi-stage non-root Docker images (separate CPU and GPU builds), Kubernetes manifests (deployments, HPA, network policies, PDB), Redis- externalised state for stateless pod scaling, and vLLM serving with continuous batching and prefix caching.
  • Observability & Evaluation: Prometheus metrics, AlertManager rules and per-turn tracing; validated with 61 PyTest cases and golden evaluation sets covering routing, retrieval and safety.
